## Create a data dictionary file 
1. Identify a dataset for which you want to create a data dictionary.
1. Open the file you want to create a data dictionary for.
2. Create a new spreadsheet in the same location, name it 'data_dictionary' or [use this template](TO DO: add link to file)
3. Add the following headings to the data_dictionary file:
'variable name', 'readable variable name', 'measurement unit'. 'allowed values', 'definition of the variable',	'description of the variable' 
4. Add the column headings from the data file to the first column of the data_dictionary
5. Start adding content to your data dictionary
6. Consider identifying a suitable repository for your datatype to match your variables to the metadata standards for that repository.
7. Consider looking for ontology terms that match your allowed values
 

More guidance can be found in the metadata module, the [Open Science Framework Support](https://help.osf.io/article/217-how-to-make-a-data-dictionary) and on [SciLifeLab RDM Guidelines](https://data-guidelines.scilifelab.se/topics/metadata/)
