> ### About this activity
**Objectives:**
- Start creating a README file for your own project
- To organise your files and folders in a structured way 
- To simplify collaboration with others
> 
{: .callout}


## Create a README file 
1. Consider at what level you want to create a README file. It can be at the root of your project, in a specific folder or in a specific file
2. Use a README template to get started. You can find templates [here](https://data-guidelines.scilifelab.se/topics/readme-files/)
3. Go back to the data organisation module to get inspiration for naming conventions for your files and folders

More guidance can be found in the README module and on [SciLifeLab RDM Guidelines](https://data-guidelines.scilifelab.se/topics/readme-files/)
