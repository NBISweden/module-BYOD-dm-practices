## Initiate a GitHub repository for your project
1. Go back to the Version control module, Part 3: Setting up versioning on your computer, and follow the steps in the 'Extra exercise - starting locally from scratch' using a folder on your computer where you have your project files.
2. Consider applying some of the data organisation principles you have learned in the data organisation module to your project folder
-   folder structure
-   add a README to GitHub and create a new repository for your project
4. Continue the steps in the version control module to add collaborators to your project


More guidance can be found in the README module and on [SciLifeLab RDM Guidelines](https://data-guidelines.scilifelab.se/topics/readme-files/)
