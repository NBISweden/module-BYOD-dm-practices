> ### About this activity
**Objectives:**
- Identify a suitable repository for my data
- Identify the file formats the repository accepts
- Prepare metadata for the repository
{: .callout}


## Create a data publication plan for your project
1. Identify the set of files that you want to publish
2. Go back to the second part of Data Publication module (Planning for data publication)
3. Follow the steps to create a data publication plan for your own project. Consider the following questions:
- What types of outputs will you be creating or collecting?
- What are suitable repositories for your outputs?
- What are the documentation guidelines for the repositories? Which formats for data and metadata are required to be able to submit?
- Under what licenses will your research outputs be shared?

## Prepare metadata for the repository
1. Once you have identified the repository, have a look at the [SciLifeLab RDM Guidelines](https://data-guidelines.scilifelab.se/data-life-cycle/share/) to see if there are any specific guidelines or metadata templates for the repository you have chosen.
2. Start preparing the metadata required for the repository you have chosen.
3. Consider transforming files to the required formats for the repository you have chosen.

More guidance can be found in the Data piblication module and on [SciLifeLab RDM Guidelines](https://data-guidelines.scilifelab.se/topics/readme-files/)
